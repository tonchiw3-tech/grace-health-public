# GRACE｜血圧・健康管理

血圧と体重を日々記録し、最近の推移を確認できるブラウザ向けの健康管理アプリです。記録は利用しているブラウザのローカルストレージに保存されます。

## 主な機能

- 日付、最高血圧、最低血圧、脈拍、任意のメモを入力して保存
- 保存済みの血圧記録の一覧表示、編集、削除
- 直近30日間の血圧の推移と、表示開始日以降の平均値を表示
- 体重の記録、編集、削除
- 身長と目標体重の設定保存
- 入力中の体重からBMIを表示
- 直近30日間の体重の推移、7日間平均、目標体重、記録日数を表示
- 直近30日間の血圧を主治医向けレポートとして表示
- 主治医向けレポートの印刷
- スマートフォンなどの画面幅に対応したレスポンシブ表示

## 使用技術

- HTML5
- CSS3（レスポンシブ対応）
- JavaScript（ブラウザ標準API）
- Canvas API（血圧・体重グラフ）
- `localStorage`（血圧・体重・設定の保存）
- `sessionStorage`（保存完了メッセージの一時表示）

外部ライブラリやバックエンドサーバーは使用していません。

## 起動方法

### ブラウザで開く

1. `index.html` をブラウザで開きます。
2. 日付と測定値を入力し、「血圧を保存する」または「体重を保存する」を押します。

### VS Codeで開く場合

Live Serverなどのローカル開発用拡張機能を利用して、プロジェクトの `index.html` を起動してください。静的ファイルだけで動作するため、Node.jsやデータベースの起動は必要ありません。

## 保存方法

記録はサーバーやクラウドには送信されず、使用中のブラウザのローカルストレージに保存されます。

- 血圧記録: `graceHealthBloodPressureRecordsV2`
- 体重記録: `graceHealthWeightRecordsV1`
- 身長・目標体重: `graceHealthWeightSettingsV1`

そのため、同じブラウザ・同じ端末で開いた場合に記録を利用できます。ブラウザのサイトデータ削除、プライベートブラウジングの終了、端末変更などにより記録が利用できなくなる場合があります。現状、アカウント同期、クラウドバックアップ、データのエクスポート機能はありません。

## 医療上の注意事項

- このアプリは測定値の記録と可視化を補助するもので、診断、治療、緊急時の判断を行うものではありません。
- 入力する値は実際に測定した値を使用し、表示された平均値やグラフだけで健康状態を判断しないでください。
- 気になる症状や測定値の変化がある場合は、自己判断で薬を変更・中止せず、主治医または医療機関に相談してください。
- 強い胸痛、呼吸困難、意識障害など緊急性が疑われる症状がある場合は、このアプリを使わず、地域の救急窓口へ連絡してください。
- BMIは身長と体重から算出する参考値であり、健康状態を判定する診断結果ではありません。
